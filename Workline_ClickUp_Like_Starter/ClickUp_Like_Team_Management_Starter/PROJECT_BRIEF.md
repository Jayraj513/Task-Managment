# Product Brief — Workline

## Working name
Workline (name can be changed). Brand and UI must be original; use ClickUp only as a feature/UX reference.

## Primary users
1. **Workspace Admin / Manager** — creates projects, allocates tasks, checks progress, approves workflow changes, sees reports.
2. **Team Lead** — manages projects/tasks and reviews team workload.
3. **Team Member** — sees assigned work, updates status/progress, logs time, comments, attaches evidence.
4. **Viewer** — read-only access to approved dashboards/projects.

## Problems to solve
- Tasks are scattered across chats and spreadsheets.
- Managers cannot quickly see who owns what, what is late, and what is blocked.
- Team members lack one clear daily task list.
- Leadership needs project and team performance dashboards.

## MVP outcomes
- Create projects and tasks, assign users, set priorities and due dates.
- Kanban, List, Calendar and Gantt views.
- Comments, activity history, subtasks, dependencies, attachments.
- Role-based access and audit-friendly history.
- Manager dashboard, individual dashboard, team workload and exportable reports.
- Demo seed data that makes the application understandable in a 5-minute walkthrough.

## Out of scope for first version
Full chat/video conferencing, AI agents, whiteboards, external integrations marketplace, complex billing, mobile native apps, advanced custom automation builder. Keep architecture extensible, but do not build these before the core workflows work.

## Success metrics for the first internal pilot
- 90% of active tasks have an owner and due date.
- Manager can identify overdue/blocked tasks in under 30 seconds.
- Every user can find their top priorities in under 10 seconds.
- Dashboard totals match filtered task records.
- No user can edit another project without permission.
